# BLACKCYBER

A local-first crypto ecosystem research and incident archive prototype, with searchable projects, ecosystem index, people/roles and evidence links.

## Run locally

Open `index.html` in a browser (Chrome, Safari, Firefox). No build or backend needed.

## Structure

- `index.html`: standalone prototype (HTML, CSS and JavaScript)
- `.gitignore`: ignores local editor and OS files

## Limitations

- Research prototype with limited entries, **not** a complete or live blockchain database.
- Incident figures refer to differing metrics; do not aggregate them into a total loss figure.
- A person or ecosystem being mentioned does not itself imply wrongdoing. Legal status should be checked against primary sources and updated regularly.
- No server, accounts, or submission storage. External image links may require a network connection.

## Publishing

A GitHub Pages deployment can use the root `index.html` after the repository is made public and Pages is explicitly enabled. This project is intended to begin as a private repository.
